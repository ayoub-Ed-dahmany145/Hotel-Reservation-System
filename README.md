# Hotel Reservation System

A full-stack hotel reservation web application developed using React, Node.js, Express.js, and MySQL.

## Features

- User Authentication
- Browse Hotels
- Hotel Details
- Book Hotels
- Responsive Design

## Technologies

- React.js
- Node.js
- Express.js
- MySQL
